# Race Planner — documents publics

La politique de confidentialité de l'application Android **Race Planner**, servie par
GitHub Pages à l'adresse <https://simonarnaud.github.io/race-planner-legal/>.

C'est cette URL qui est déclarée dans la Console Google Play. Elle doit rester stable :
un lien mort ou déplacé fait échouer l'examen de la fiche.

`index.html` est la source. **Si ce qui sort de l'appareil change** — un service appelé,
une donnée conservée, une autorisation demandée — cette page se met à jour dans le même
mouvement, et la date en tête avec elle.

Le code de l'application vit dans un dépôt séparé et privé.
